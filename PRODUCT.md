# Product brief — Portfolio hub

## Name

henriquemoreira.eu (portfolio)

## One-liner

Personal hiring / reskilling portfolio; **GRYPS** is the lead skill demo; then **Triangora**, then **Morea**; archives and FORGE sit in “also built.”

## Audience

Hiring evaluators and peers scanning skill demos (~60s path: Home → About → Capabilities → Work → GRYPS Advisor).

## Job to be done

Understand Henrique as an international industrial B2B professional evolving through applied AI (not reinventing as an AI engineer); try the GRYPS prototype; skim Triangora / Morea; download CV / LinkedIn; understand non-commercial posture.

## Surface types

- Marketing / landing: yes (Persuade — person-first hero)
- Case / Read: `/work/gryps`, `/work/morea`
- App screens: none (links out to prototypes)

## Constraints

- Stack: Vite + React 19 + React Router; inline styles (+ minimal global CSS)
- FORGE: list as private only — no public login
- Triangora: live Vercel link only; GitHub stays private while under development
- CTAs: **Explore the GRYPS prototype** / **Verify in a minute** / **Open prototype** / **Download CV**
- Commercial status: non-commercial / reskilling (Finnish unemployment fund until further notice)

## Honesty

No SaaS, pricing, waitlists, or “production customer” claims. Seed/demo numbers are illustrative where noted on GRYPS. Do not present evolving AI capabilities as 18 years of AI experience. FORGE stays private-only.

## Success look

First viewport: **brand monument + B2B identity + punchline + Explore the GRYPS prototype / Get in touch** — quiet non-commercial note. Then About → Capabilities → Work (Monopati trust → GRYPS → Triangora → Morea → also built) → Contact (CV + LinkedIn).

## Maintain (do not regress)

- **Person-first hero** — `HENRIQUE` / `MOREIRA` monument; amber brand; Lycaon constellation.
- **Business foundation first** — international industrial B2B experience; AI as evolution, not replacement.
- **Lead with the system under Work** — GRYPS first with live screenshots; never a stack badge wall on the home hero.
- **Stack as case evidence** — on `/work/gryps` and featured cards.
- **Stamps secondary** — SAP / Power BI / CRM / BW stay in About footnote, not the headline.
- **60s path** — Home → About → Capabilities → Work → explore the GRYPS prototype. Shared copy in `src/copy.js`.
- **Hub footer stack** — only technologies this repo uses (Vite · React · Router · Vercel).
