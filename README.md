# Portfolio — Henrique Moreira

Personal site hub for Henrique Moreira (Espoo, Finland). Public, indexed **hiring / reskilling portfolio**: person-first hero; Work lists **GRYPS** (lead Signature demo) → **Triangora** → **Morea**, then quieter archives. Reskilling posture under Finnish unemployment fund until further notice — non-commercial.

**Not a SaaS storefront.** Prototypes are non-commercial / research / skill demonstrations. CTAs use **Open prototype** / **Generate a Resilience Signature**.

**Live:** [henriquemoreira.eu](https://henriquemoreira.eu)

## What’s on the site

- Person-first hero — brand + value subline + See GRYPS / Get in touch
- Why me — commercial judgment behind the build
- Work: Monopati trust → GRYPS → Triangora → Morea → also built (archives, FORGE)
- Mission briefs: `/work/gryps`, `/work/morea`
- Contact: Download CV + LinkedIn; email secondary
- Dark theater + Arctic-day light theme (persisted preference)
- Privacy / Terms / About

## Stack

- Vite + React 19 + React Router
- Pure inline styles (+ minimal `index.css`)
- Canvas constellation particle system
- `@vercel/analytics` (cookieless)
- Deployed on Vercel

## Local development

```bash
npm install
npm run dev
```

```bash
npm run lint
npm run build
```

No API keys are required for local development. Never commit secrets; see [`.env.example`](./.env.example) and [`SECURITY.md`](./SECURITY.md).
